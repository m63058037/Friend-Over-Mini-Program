# 搅屎棍 使用说明

## 简介
本程序是一个轻量级的鼻屎弄得奶奶笑工具，运行后会让用户完成一个简短的互动问答，适合在朋友之间作为无害玩笑使用。
可以在下载页面内下载所需要的运行文件

## 运行方式
- 双击 引导文件 即可运行，无需安装、无需管理员权限。
- 首次运行会弹出一个询问窗口，然后你的朋友就会崩溃。
- 后续重启后会关闭程序，无界面、无打扰。

## 行为说明
1. 首次运行：
   - 弹出提问“你是不是猪？”，选择“否”会出现几个的小窗口。
   - 随后显示全屏输入页，提示输入让你的朋友变成蠢猪（不区分大小写）。
   - 输入正确后程序自动退出，你的朋友，我就可以继续享受电脑了，所以你可以再运行一次。

2. 有什么用：
 仅仅让你那个爱内卷的朋友破防而已

3. 完全退出：
   - 无退出方式（无托盘菜单、无命令行参数）。
   - 否则自己想办法

## 适用环境
- Windows 10 / 11 (x64)
- 无需额外运行时，单文件即可运行
